# Project security requirements and evidence

## Purpose
The adopting project's security owner records its threat model, required controls and verification evidence here. This is a project-document template, not a certification or Sentinel implementation.

## Scope
Record trust boundaries, input validation, access-control allow/deny cases, secrets handling, dependencies and required session/token properties. Actual provider/session settings belong to [AUTH.md](AUTH.md). Vulnerability reporting belongs to the adopting repository's root SECURITY.md.

## Evidence
Record exact checks, results, gaps and owner decisions. Sentinel guidance may be adopted explicitly; no automatic scanner or auth provider is installed by this template.
