# Engineering roles

Architect, backend, frontend, data, DevOps, QA and technical writer are responsibility lenses for engineering work. Product ownership stays with the adopting project. Use Meridian designer guidance and Sentinel security review when appropriate; neither is required to install Axis.

See the role files in this directory. Required-reading paths refer to adopter document slots and the project's actual implementation; resolve material gaps before acting.

Optional specialist guidance: [Meridian designer](https://github.com/pedrobritx/meridian/blob/main/agents/designer.md) and [Sentinel security review](https://github.com/pedrobritx/sentinel/blob/main/playbooks/security_review.md). These references do not import governance or runtime code.
