# Axis contributor entry point

Read README.md and PROJECT_RULES.md, inspect the affected source and tests, then select applicable roles/playbooks. Project files under docs/, constraints/, knowledge/ and memory/ are adopter templates; do not mistake empty slots for implemented capability.

Axis is usable without full Polaris governance. A project may opt in explicitly. Designer/security collaboration references are optional; provide the adopting project's context when using a specialist review. Never infer permission to configure an external service from a recipe.

Run the documented validation and relevant behaviour checks. Update STATUS.md and HANDOFF.md when state changes or unfinished work remains.

For a composed task, read the local discipline.json and the supplied project context. Return evidence and blockers with the original request ID; keep product-specific changes in the adopting product. A missing or excluded peer discipline never grants an automatic assurance pass.
